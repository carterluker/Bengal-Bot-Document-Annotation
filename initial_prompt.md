# Bengal Bot Interactive Document Annotation Demo

## Overview

BengalBot is a newly funded ISU project led by faculty in English, Computer Science, and the College of Technology. The team is building ISU’s own AI writing-feedback tool, built into Canvas. Right now, the AI feedback a student gets often depends on which tool they can afford. BengalBot is meant to give every ISU student the same access to a feedback tool that knows their course and their assignment. It also allows us to have data Sovreignty, keeping ISU data on ISU servers. 

The project is in the early stages, therefore the team is looking for feedback and feature ideas to include in this tool. This repository will house a **prototype** for one of those features: interactive document annotation.

## Feature: Interactive Document Annotation

A common complaint amoung students, when using AI for writing feedback, if difficulty determining where feedback applies to there writing. My idea is as follows:

1. Students can upload a draft of their writing.
2. A preview of the document is displayed, with sections needed improvement boxed or highlighted.
3. Students can hover over or select the highlighted areas to receive more information, or provide an additional prompt asking for clarification.
